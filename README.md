# FitLog

FitLog is a modern fitness tracking app designed to help users discover exercises, build a personalized workout plan, and stay motivated with clear exercise details and progress cues.

## Overview

The app gives fitness enthusiasts a streamlined experience for exploring a curated exercise library, reviewing key workout details, and organizing both their daily plan and saved exercises. It combines a clean, high-contrast interface with practical workout planning features to make training more focused and engaging.

## Technologies Used

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- DaisyUI
- React Icons
- React Toastify
- ESLint

## Key Features

1. Exercise library with curated workout cards
   - Browse a wide range of exercises with details like difficulty, equipment, calories burned, and duration.

2. Personalized workout planning
   - Add exercises to a daily plan and keep track of the workouts you want to complete.

3. Saved exercise management
   - Save favorite lifts and revisit them later without losing momentum in your training routine.

4. Detailed exercise information
   - View specific workout instructions, ratings, and muscle group information for each exercise.

5. Progress-focused dashboard
   - Monitor totals such as minutes and calories across your current plan to stay aware of training volume.

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
npm install
```

### Run the app locally

```bash
npm run dev
```

Open http://localhost:3000 in your browser to view the app.
